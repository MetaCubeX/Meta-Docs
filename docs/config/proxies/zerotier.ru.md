## network

Идентификатор сети ZeroTier.

## state-dir

Опционально. Каталог для хранения постоянной идентификации узла; по умолчанию используется изолированный каталог, создаваемый на основе идентификатора сети и имени исходящего соединения.

## planet

Опционально. Путь к файлу частной планеты (Planet), используемый для замены встроенной планеты Earth.

## mtu

Опционально. Значение локального MTU для переопределения; не может превышать MTU, предоставленный контроллером ZeroTier.

## physical-mtu

Опционально. MTU полезной нагрузки UDP ZeroTier. Допустимый диапазон: `510-10324`, значение по умолчанию: `1432`.

## primary-port

Опционально. Основной UDP-порт; значение `0` — автоматический выбор доступного порта.

## secondary-port

Опционально. Вторичный UDP-порт; `0` — автоматический выбор, `-1` — отключить.

## tcp-fallback-mode

Опционально. Режим аварийного переключения на TCP. Доступные значения:

* `auto`: Использовать ретрансляцию после сбоя UDP-соединения.
* `force`: Использовать только ретрансляцию.
* `disable`: Отключить аварийный переход на TCP-ретрансляцию.

По умолчанию: `auto`.

## tcp-fallback-relay

Опционально. Адрес сервера TCP-ретрансляции при аварийном переключении.

## remote-trace-target

Опционально. Идентификатор узла ZeroTier, на который будут отправляться глобальные диагностические трассировки.

## remote-trace-level

Опционально. Уровень удалённой диагностической трассировки. Доступные значения:

* `0`: Обычный
* `10`: Подробный
* `15`: Правила
* `20`: Отладка
* `30`: Чрезмерный

## low-bandwidth

Опционально. Включить режим низкой пропускной способности. По умолчанию: `false`.

## encrypted-hello

Опционально. По умолчанию: `false`.

## orbit

Опционально. Настройка списка частных корневых серверов (moon).

### orbit-world

Идентификатор мира Moon (Moon World ID), должен быть 16-значной шестнадцатеричной строкой.

### orbit-seed

Идентификатор корневого узла Moon, должен быть 10-значным числом.

## udp

Включить ли UDP. По умолчанию: `true`.

## remote-dns-resolve

Опционально. Разрешать ли целевые доменные имена через ZeroTier с использованием DNS-серверов, предоставленных контроллером.

## dns

Опционально. Переопределить DNS-серверы, предоставляемые контроллером; можно указать один или несколько адресов.

## dialer-proxy

Опционально. Передавать трафик ZeroTier через другое исходящее прокси, где `ss1` — имя другого прокси-узла.

## interface-name

Опционально. Указать имя сетевого интерфейса, используемого ZeroTier.

## routing-mark

Опционально. Установить маркер маршрутизации Linux.

## ip-version

Опционально. Указать предпочтение версии IP-протокола.
