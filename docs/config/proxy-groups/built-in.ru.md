# Предопределенные группы прокси

## GLOBAL

По умолчанию включает все группы прокси и прокси-узлы

Эта группа стратегий также может быть настроена в конфигурационном файле

Однако веб-панель и некоторые клиентские приложения выполняют сортировку в соответствии с порядком групп политик в группе политик GLOBAL

При настройке группы политик GLOBAL рекомендуется полностью расписать все группы политик текущей конфигурации (кроме самой GLOBAL)

Если группа GLOBAL не настроена и в ней ничего не выбрано, выбран её первый элемент — `DIRECT`. В этом случае при переключении в режим `global` весь трафик идёт напрямую. Если в GLOBAL выбрана политика, переключение между режимами `rule` и `global` этот выбор сохраняет.

Чтобы задать начальный выбор GLOBAL, настройте группу GLOBAL и укажите [`default-selected`](./index.md#default-selected):

```{.yaml linenums="1"}
proxy-groups:
  - name: GLOBAL
    type: select
    proxies: [proxy-a, proxy-b, DIRECT]
    default-selected: proxy-a
```
